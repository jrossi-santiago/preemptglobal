# Preempt Global — LinkedIn Content Framework
*Reference doc for the LinkedIn content-writing agent. Text-only, written in one weekly batch, spaced across the week via LinkedIn's native scheduler.*

**2026-08-03 migration note:** this doc previously ran a 7-type system (Conviction, Story, Midas, Doc, Hot Take, Transformation, Vulnerability). That system is retired. Everything below implements the High-Ticket Sniper System's 4-format taxonomy from `STRATEGY.md`. If you're looking at an old calendar entry or old post using one of the retired type names, treat it as historical — don't write new posts under those labels.

## How this doc fits with the other files

This framework governs **what to write about and how a post is structured** (format, weekly mix, topic bank). It does not contain tone, vocabulary, or hook-writing rules — those live elsewhere, and this doc defers to them completely:

- **`STRATEGY.md`** — the master strategy this whole system implements. Read it first. Operating principle: we write for the ~200–2,000 people who can retain us this quarter, not for reach.
- **`BRAND_VOICE.md`** — the only source for tone, vocabulary, sentence mechanics, terminology accuracy, and the accurate description of the industry problem Preempt Global solves (Section 4). Section 1 of that doc also covers all business facts (offer, pricing, stats, guarantee). Read this in full before writing any post.
- **`BUYER_PROFILE.md`** — the buyer resolution document (Strategy Phase 0, #4). Read this before drafting any post — every post should be written at this level of specificity about the reader's actual Tuesday, not a generic industry pain point.
- **`UNFAIR_ADVANTAGE.md`** — the filter rule: if a competitor could have written the post, it doesn't publish. Run every topic through this before writing.
- **`SWIPE_PATTERNS.md`** — the only source for hook mechanics and structural performance data on Preempt's own past posts (direct-address hooks, framework+CTA structure, formatting experiments). This framework tells you *which format to write*; the swipe-patterns file tells you *how to structure the hook and close once you know the format*.
- **`COMPETITOR_SWIPE_FILE.md`** — the Phase 0 research-sprint swipe file of outside creators' top-performing posts. Currently a scaffold, not yet populated — see that file for what's needed before it's usable.
- **`CONVERSION_PLAYBOOK.md`** — what happens after a post generates a DM. Human-executed, not part of this writing routine, but the CTA rules below hand off directly into it.

If anything below conflicts with `BRAND_VOICE.md` or `SWIPE_PATTERNS.md` on tone, wording, or hook style, **those two win.** This framework only governs topic selection, format, and weekly cadence.

## Post Formats

Every post is one of these 4 formats, per `STRATEGY.md` Phase 1.

### Format 1 — Full-System Giveaway (flagship, 2x/week)
Give away an entire named framework or system, start to finish — every step, real numbers, the exact order. No teasing, no "3 of 7 steps." Then show the terrain: how long it actually takes to run, what fails the first few times, the fragile details that only make sense after getting burned, the step that rots if not done fast enough.
- **The giveaway is the credential. The difficulty is the pitch.** If it looks easy, the reader runs it himself. If it looks complete *and* brutal to operate well, he reaches out.
- This is the highest-performing structure in Preempt's own swipe-pattern data (`SWIPE_PATTERNS.md` Section 5, #2 and #3 — named framework + explicit CTA is the single best-converting pattern recorded). Default to this format whenever a topic is teachable as a repeatable method (Set-of-Record Check, Three-Touch Rule, and similar named systems belong here).
- **Carries the CTA.** Close with the flat line from `CONVERSION_PLAYBOOK.md`: *"If this is you, my DMs are open — not free."*
- Length: no fixed cap since the point is completeness, but expect 250–500 words. Don't pad; stop when the system's been fully given away and the terrain's been shown.

### Format 2 — Case Study Breakdown (1–2x/week)
Lead with a real result and real numbers, pulled from `BRAND_VOICE.md` Section 1 (e.g. $78,900 avoided / 32 days protected) or a specific finding-level figure — never rounded or invented-sounding. Walk through exactly how it was achieved, step by step. Preempt's involvement shows up late and naturally, as one step in the process, never as a pitch.
- **Carries the CTA.** Same flat DM line as Format 1 — a reader who just watched the mechanism work doesn't need to be sold, just told the door is open.
- Length: 165–250 words.

### Format 3 — Short-Form High-Signal (2x/week)
One sharp observation, pattern, or contrarian read that only someone reviewing sets at Preempt's depth could make — a Hot Take or Conviction-style belief, stated with zero hedging, always targeting the specific broken process in `BRAND_VOICE.md` Section 4, never a vague industry complaint or a named competitor/trade.
- **No CTA.** Close on the stated belief or an aphorism, per the swipe-pattern data on this style (`SWIPE_PATTERNS.md` — aphorism-close narrative posts are the established pattern here; don't append the DM line to this format).
- Length: 60–120 words.

### Format 4 — Personality (1x/week)
Opinions, taste, attitude, how we think, including real setbacks and what they taught (this format absorbs what used to be the standalone Vulnerability type — a true failure, told straight, is personality material, not its own category). This is how the lurker decides whether he *likes* us, and per `STRATEGY.md` it closes deals that proof alone doesn't.
- **No CTA.** Same reasoning as Format 3 — this format's job is trust, not conversion.
- Rotation rule: if it's been 3+ weeks since a Personality post drew on a real failure (check `CALENDAR.md`), use this week's slot for that instead of a lighter opinion post.
- Length: 100–200 words.

Hook rule for all four formats: direct address to the reader's own situation, never "I found/reviewed X" (`SWIPE_PATTERNS.md`, Section 5, #1). Written at Tuesday-resolution per `BUYER_PROFILE.md` — describe the reader's actual situation back to him, specific enough that 95% of readers feel nothing and the right 5% feel seen.

## Weekly Mix (7 posts, daily cadence, fixed default)

- 2× Full-System Giveaway
- 2× Case Study Breakdown
- 2× Short-Form High-Signal
- 1× Personality

This lands at roughly 57% long-form / 29% short-form / 14% personality against `STRATEGY.md`'s 50/30/20 target — close enough given a 7-post week doesn't divide evenly into thirds and fifths. Full-System Giveaway and Case Study Breakdown should never both be skipped in the same week even if the mix is otherwise adjusted; they're the formats carrying the CTA and the proof.

Assign each of the 7 posts to a format before writing so the week doesn't skew all-narrative or all-framework.

## Topic Bank

Pull topics from here only — do not invent unrelated topics. Before committing to a topic, run it through `UNFAIR_ADVANTAGE.md`'s filter rule: if a generic industry account could write the same post from this topic alone, it needs Preempt's own numbers, pattern, or founder-specific detail layered in before it's chosen.

**Documentation & Process:** RFIs (writing them, response-time tracking, common mistakes), change orders (pricing disputes, scope creep, documentation, markup negotiation), submittals (review turnaround, approval bottlenecks, log tracking), document control (version control, addenda distribution, set-of-record disputes)

**Construction Administration:** owner's rep role, site visit reports, punch lists, pay applications (AIA G702/G703, retainage disputes)

**Cost & Schedule:** critical path scheduling (float, look-aheads, delay claims), budget tracking/cost codes, long-lead procurement, value engineering

**Risk & Disputes:** claims (differing site conditions, delay claims, documentation), contracts (AIA documents, indemnification, risk allocation), insurance & bonding basics

**Technology:** BIM coordination/clash detection, AI in document review, construction PM software adoption (Procore, PlanGrid, Autodesk Build), drone site surveys

**Closeout & Quality:** as-builts and O&M manuals, QA/QC processes, warranty tracking

When a topic overlaps directly with Preempt Global's own offer (QA/QC review, clash detection, submittal turnaround), lean on the vocabulary bank in Brand Voice Section 6 ("caught on paper," "independent pass," "hunting, not confirming," "who's checking the seam") rather than generic industry language.

## Post Mechanics

- Word count by format — see each format's entry above. No post runs long purely for length; Full-System Giveaways run longer only because they're giving away a complete system, not by default.
- No links in the post body — LinkedIn suppresses reach on posts with outbound links. If a post needs a link, note "[link in first comment]" instead.
- Hook: direct address to the reader, never "I found/reviewed X" (`SWIPE_PATTERNS.md`, Section 5, #1).
- **CTA:** Full-System Giveaway and Case Study Breakdown close with the flat line — *"If this is you, my DMs are open — not free."* — per `CONVERSION_PLAYBOOK.md`. Short-Form and Personality posts stay CTA-free and close on a stated principle, opinion, or aphorism. Never use a generic ask like "DM me if interested" — that collapses trust; the flat line works because it filters and flatters instead of soliciting.
- No comment-gating, no "comment WORD for the link" mechanics, ever — regardless of format.
- Specific numbers in every hook where the format calls for a result up front (Giveaway, Case Study) — outcome + timeframe + mechanism, real figures only, never rounded or invented-sounding.
- Visual proof (dashboard, findings report excerpt, calendar) where it exists and serves depth — not scroll-stopping theatrics.
- Archive consistency: don't contradict a position taken in an earlier post. The lurker reading three months of the archive at once is the actual reader we're writing for.
- Sentence rhythm: vary sentence length; avoid dense uniform paragraphs.
- No em-dashes anywhere — use a regular hyphen with spaces, per Brand Voice Section 3.
- Match `BRAND_VOICE.md` exactly on tone, vocabulary, and terminology accuracy (Section 5 — beams are placed, not poured, etc.).

## Measurement (weekly review)

Measure each post by its format's assigned job, never by likes:

| Format | Metric |
|---|---|
| Full-System Giveaway | Saves, profile visits, inbound DMs referencing it |
| Case Study Breakdown | Profile visits, inbound DMs |
| Short-Form | Impressions, follows from target-profile accounts |
| Personality | Follows, qualitative "right people engaging" |

**North-star funnel:** inbound DMs from qualified buyers → calls booked → closes → revenue (tracked in `CONVERSION_PLAYBOOK.md`'s territory, not this file). A post with 40 likes that produced one qualified DM beats a post with 4,000 likes that produced none.

**Kill rule:** any format or topic angle producing zero qualified DM conversations over 4–6 weeks gets cut from the topic bank rotation. Double down on what generates real conversations, even if reach drops.

**First 60 minutes after posting matters most for reach — reply to comments quickly.** Manual task, not something the writing routine handles.

## What We Explicitly Do NOT Do

Per `STRATEGY.md` — applies to every post regardless of format:

- Comment-gated lead magnets or one-word CTAs
- Automated DM sequences or opt-in email capture funnels
- Teasers that withhold "the real sauce" for a call
- Optimizing for impressions, followers, or likes
- Writing anything a broke audience would love and a rich buyer would scroll past
- Any generic "DM me if interested" CTA (see the CTA rule above for the one line we do use, and where)
