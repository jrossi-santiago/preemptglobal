# blog/outreach/

Working documents for a human to act on manually — outreach emails, PR,
product seeding — not published to the live site and never run through
blog/build.py.

Populated by blog/prompts/review-brief.md as
`YYYY-MM-DD-slug-review-brief.md`: product facts a third-party reviewer
would need, a list of independent outlets/communities worth pitching, and
a suggested named-author angle. Committing files here is fine; they are
just never linked from a live page.
