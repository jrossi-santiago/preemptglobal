Before You Ask

QUESTIONS ABOUT PRICING?
HERE'S THE STRAIGHT ANSWER.

How is Preempt Global priced? + –

Three tiers, all owner-paid: a one-time set review ($1,500–$7,500 per review), per-project coverage from the initial set through permit/GMP ($10,000–$25,000 per project), and a monthly retainer for teams running multiple active projects at once ($3,500–$7,500/mo). Custom packages are available for anything that doesn't fit those three.

What's included in every tier? + –

An NDA signed before any drawings move, a full review of the issued set across every discipline, a written findings report — every conflict located by sheet and detail, severity-ranked, with a dollar exposure and schedule impact on each — a 48-hour turnaround, and the $50K-exposure-or-free guarantee. No tier ships a lighter version of the report.

What happens if the review doesn't find $50,000 in exposure? + –

You don't pay for it. No partial credit, no fine print, on every pricing tier. If the review doesn't surface at least $50,000 in documented cost exposure, the review is free.

Which pricing tier is right for my project? + –

One-time is built for a single issued set that needs one clean pass. Per-project is built for one project's full lifecycle, catching every bulletin and RFI-driven revision along the way. Monthly retainer is built for teams with multiple active projects running at once, folded into one flat monthly number. If none of those fit, ask about a custom package.

Can I pause or cancel a retainer? + –

Yes — the monthly retainer can be paused or cancelled anytime. The one-time and per-project tiers are single engagements, not subscriptions, so there's nothing to cancel once the review is delivered.

Is there a minimum project size to work with Preempt Global? + –

No. There's no minimum construction value on any tier. The deciding factor is coordination complexity — any set with multiple trades sharing tight coordination is a fit, regardless of project size. See the full breakdown on what a construction document review actually catches.
